# OfertaFlow 3.0

Repositório destinado à aplicação OfertaFlow 3.0.

## Hospedagem

O frontend será publicado no GitHub Pages via GitHub Actions. O GitHub Pages é hospedagem estática; Supabase, autenticação, banco de dados e funções de servidor precisam permanecer em um serviço externo.

## Próximas etapas

1. Adicionar o código-fonte do OfertaFlow na raiz deste repositório.
2. Conferir as variáveis de ambiente e as dependências privadas sem publicar credenciais.
3. Em Settings > Pages, selecionar GitHub Actions.
4. Validar o build e o deploy.
